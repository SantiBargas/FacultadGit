=============================================================================
MACHETE DE COMANDOS CISCO - AUDITORÍA Y TROUBLESHOOTING
=============================================================================

1. CONFIGURACIÓN Y MEMORIA
show running-config         ! Muestra la config actual activa en la RAM (todo lo que tipeaste).
show startup-config         ! Muestra la config guardada en NVRAM (lo que cargará si reiniciás).
write memory                ! Guarda la configuración actual para que no se borre al apagar.

2. INTERFACES Y CABLES
show ip interface brief     ! Resumen rápido de las IPs y estado (up/down) de todas las patas.
show controllers serial 2/0 ! Muestra si el cable serial es DCE (necesita clock rate) o DTE.

3. RUTEO GENERAL
show ip route               ! Muestra la tabla de ruteo (rutas C, S, R, O). El comando más importante.
show ip protocols           ! Muestra información y timers de los protocolos de ruteo activos.

4. OSPF
show ip ospf neighbor       ! Muestra los routers vecinos conectados (el state debe decir FULL).
show ip ospf interface      ! Verifica a qué área (ej: Area 0) pertenece cada interfaz.

5. RIP
show ip rip database        ! Muestra todas las redes que el protocolo RIP aprendió.

6. CAZA DE ERRORES (TRAZABILIDAD)
ping [IP]                   ! Verifica si hay respuesta de un origen a un destino.
traceroute [IP]             ! (En Router) Muestra salto por salto, router por router, el viaje del paquete.
tracert [IP]                ! (En PC - CMD) Hace lo mismo que traceroute, pero desde la computadora.
=============================================================================
